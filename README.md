# 🚀 Employee Management System

A full-stack **Employee Management System** web application built with:

- **Frontend:** React (Vite) + Tailwind CSS  
- **Backend:** Spring Boot, Spring Data JPA, Spring Security (JWT)  
- **Database:** MySQL

---

## 📌 Features

- 🔐 **Secure Authentication** using JWT and Spring Security
- 👨‍💼 **Add, Edit, Delete, View** Employee Records
- 📋 **Responsive Dashboard** built with React + Tailwind
- 🔎 **Search and Filter** Employees
- 🌐 RESTful API Integration
- 📱 **Fully Responsive** UI for all screen sizes

---
